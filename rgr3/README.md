# РГР №3. Векторная модель текста

В папке реализовано **задание 1** (первая часть работы).

## Тексты

Для русского и английского языков выбрано по два текста из того же корпуса,
который использовался в работе №1: `wikimedia/wikipedia`, версия `20231101`
(см. `config.py`).

| Язык | Текст 1 | Текст 2 | Слов в тексте 1 | Слов в тексте 2 |
|---|---|---|---:|---:|
| Русский | Литва | Кавказские Минеральные Воды | 5 908 | 5 737 |
| Английский | Anarchism | Ayn Rand | 6 712 | 6 230 |

Исходные тексты сохранены в `rgr3/data/texts/`, метаданные — в
`rgr3/data/texts_metadata.json`. Скрипт `rgr3/fetch_texts.py` заново загружает
эти четыре статьи из датасета.

Если в работе №1 использовались другие два текста, достаточно заменить
`ru_1.txt`, `ru_2.txt`, `en_1.txt`, `en_2.txt` в `rgr3/data/texts/`,
обновить названия в `texts_metadata.json` и перезапустить `vector_model.py`
и notebook.

## Что сделано

1. Токенизация (регулярные выражения, как в работе №1).
2. Нормализация — лемматизация с помощью `simplemma`.
3. Удаление стоп-слов (список служебных слов из РГР №2 + лемматизированные
   формы).
4. Модель **one-hot encoding**: бинарные векторы в общем словаре пары текстов.
5. Модель **TF**: векторы относительных частот слов.
6. Для one-hot модели найдено пересечение мультимножеств (общие уникальные
   слова, пересечение с кратностями, коэффициент Жаккара).
7. Для TF модели найден косинусный коэффициент.

## Файлы

- `01_vector_models.ipynb` — основной notebook с пошаговым выполнением задания
  и выводами (уже выполнен).
- `vector_model.py` — функции предобработки, построения моделей и расчёта
  метрик; его же можно запустить как скрипт.
- `fetch_texts.py` — загрузка четырёх текстов из датасета.
- `data/texts/` — исходные тексты.
- `data/texts_metadata.json` — названия, ссылки и размеры текстов.
- `data/task1_results.json` — полные результаты (топы слов, общие слова,
  TF-термы).
- `data/task1_summary.csv` — итоговая таблица.
- `figures/task1_top_tf.png` — график топ-10 TF-термов (строится в notebook).
- `build_report.py` — сборка отчёта Word/PDF по результатам задания 1.
- `report/РГР_3_отчет.docx` и `report/РГР_3_отчет.pdf` — готовый отчёт по
  заданию 1 (титульный лист, содержание, таблицы, рисунок, выводы).

## Отчёт

В `build_report.py` на титульном листе используются поля `STUDENT`, `COURSE`
и `GROUP`. Замените их на свои данные и перезапустите скрипт либо отредактируйте
готовый `report/РГР_3_отчет.docx` в Word.

## Запуск

Из корня репозитория:

```bash
.venv/bin/python rgr3/fetch_texts.py
.venv/bin/python rgr3/vector_model.py
.venv/bin/jupyter nbconvert --to notebook --execute --inplace rgr3/01_vector_models.ipynb
.venv/bin/python rgr3/build_report.py
```
